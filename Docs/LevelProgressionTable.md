## Key Progression Summary

Keys are introduced progressively based on their difficulty:

| Levels | Key Emphasis |
|--------|--------------|
| 1–10 | C major only |
| 11–20 | C, G, F (1-2 sharps/flats max) |
| 21–40 | Expanded to D, Bb, A, Eb (up to 3 sharps/flats) |
| 41–70 | Further expansion (up to 4-5 sharps/flats) |
| 71–100 | All keys including enharmonic equivalents |

The system uses **balanced key selection** that maintains 50% flat vs. sharp distribution while respecting each scale's authentic key signatures.

## Additional Technical Settings

### Max Melodic Interval (Semitones)
- **L1–10:** 2 semitones (whole step max)
- **L11–20:** 3 semitones (minor third)
- **L21–40:** 3–4 semitones
- **L41–60:** 4–5 semitones
- **L61–80:** 5–6 semitones
- **L81–100:** 8 semitones (minor sixth)

### Measure Batch Size
- **L1–5:** 1 measure
- **L6–10:** 2 measures
- **L11–30:** 4 measures
- **L31–100:** 8 measures

This determines how many measures are generated at once during level practice sessions.

## Implementation Notes

**Source Files:**
- `Services/LevelProgression.cs` - Core level progression logic
- `Services/DifficultyLevelMapper.cs` - Applies level settings to sessions
- `Services/KeyDifficultyRules.cs` - Key progression and validation
- `ViewModels/SettingsPageViewModel.cs` - Factory defaults
- `Services/SettingsResetService.cs` - Reset logic

**Data Structure:**
- Levels are grouped into 10-level bands (decades)
- Each band has a stage label and main pedagogical focus
- Settings interpolate smoothly within bands where appropriate
- Scale and key pools use weighted random selection
- Range expands gradually to accommodate more advanced playing
