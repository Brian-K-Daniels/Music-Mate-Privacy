Introduction

Welcome to Music Mate

Music Mate is designed to help you improve your instrument skills in an efficient and enjoyable way. This guide provides an overview of core features and instructions to help you get started quickly.

Music Mate listens to your playing and provides real-time feedback on your accuracy. As you play, the app shows when you hit the correct notes and tracks your performance over time.

One of the available exercises is Random Mode. In this mode, Music Mate generates a sequence of notes with interval patterns typical of musical melody. Only notes that you have not yet mastered are included, so practice time focuses on areas where improvement is needed.

You can define what “mastered” means by adjusting the Correct Threshold (%) slider in Settings. For example, if you set the threshold to 90%, notes you have played correctly at least 90% of the time will be excluded from Random Mode.

You may also adjust the overall note range. Starting with a moderate range such as C4–C5 is recommended. As your skill increases, extend the range to challenge yourself further.

The hamburger menu leads you to one of 6 pages.

If you prefer to explore the app without reading detailed instructions, feel free to tap around — you can’t break anything. There is a “Reset” button which will restore the factory settings.

Features

Navigation

Music Mate uses a standard navigation menu located at the top left of the screen. Tap the menu icon (☰) to view available pages, then select the destination you wish to access. The current page title is displayed next to the menu icon. To return to the Home page from any section, use the back arrow. Drag to scroll up or down. Change the background color by using the button at the bottom of the main page.

Pages

  • Home – Main practice interface
  • Settings – Configure practice parameters
  • Statistics – View performance history
  • Advanced – Advanced settings
  • About – Information and support
  • Tuner – Display of a single note heard in various formats.

Home Page

Staff and Notes

The Home page displays a musical staff with a treble clef. In the default configuration a sequence of quarter notes appears, ascending and descending over one octave.

Feedback Display

Below the staff is a row of feedback indicators. Each indicator corresponds to the note above it displayed on the staff.

  • An indicator turns green when you play correct note.
  • If a note is incorrect, no change appears, but the attempt is recorded
  • The number shown indicates how many cents your pitch deviates from the target (100 cents = one semitone).

Buttons and Controls

Auto Play

This triangular button plays the displayed tune using a synthesized reference tone. This helps you learn the sound of a scale.

Start / Stop Listening

  • When the button shows a green circle, tap to start listening and refresh the notes
  • When it shows a red square, tap to stop listening

Instrument

Select your instrument from a list grouped by key. Your choice is remembered.

Key

Displays the key signature (transposed for your instrument). The concert key is shown in the top-left label. This picker is not always visible.

Tune

Pick one of three “tunes”

Selected Scale

The scale e.g. C Major, Eb Harmonic Minor is selected on the Settings page.

Random

Random notes are generated based on:

  • Selected note range
  • Realistic melodic intervals
  • A configurable percentage of accidentals
  • Exclusion of notes you have mastered

The threshold is controlled by “Omit notes at/above % correct.”

This uses the statistics shown on the Statistics page. Notes above the selected threshold are excluded (once played enough times).

A Repeat button allows automatic generation of a new random sequence after the current one is completed.

Tuner

This page displays a staff on the left and a tuner on the right. When you play a note it is drawn on the staff and its name is displayed on the right. For example if you play middle C it will display C4. It will also display the deviation from the standard frequency in cents (100 cents = 1 semitone). The two frequencies are also shown. The Key picker is not shown for the tuner.

Click to select background.

This displays a tool to select the background color of the staff panel. The same color is used for the background of other pages. You can scroll the tool up and down. When you see a color you like in the preview panel at the bottom left, tap the OK button and the tool will close.

Reset Button

A tap will make all settings revert to the factory default values.

Settings Page

  • Scale – Select one of 12 scales
  • Lowest / Highest – Define the note range
  • Playback BPM – tempo when the device plays notes (Auto Play)
  • Music BPM – written tempo on the score (quarter note = value)
  • Accidental % – Percentage of accidentals in Random mode
  • Omit notes at/above % correct – Excludes well-mastered notes
  • Minimum Correct Count – Minimum attempts before a note is evaluated
  • Auto start on appear – Automatically begin listening when the app opens

Statistics Page

Database

Pick either Note or Session data.

Clear All

Clears the selected database

Note data

Each row shows the

  • name of the note
  • octave number
  • number of times the note was heard to have been played correctly (c)
  • number of times the note was heard to have been played incorrectly (w)
  • percentage of times it was heard to be correct (100 * c / (c + w)).

Session data

A session is completed when all the notes on the staff have been played correctly, in order from left to right. When a session is completed information about it is stored in the next row of this table. Each row shows the

  • date and time when the session was completed
  • key of the music (transposed for the instrument)
  • “tune”
  • key of the instrument
  • scale (blank for random)
  • highest note allowed
  • lowest note allowed
  • detected tempo in beats per minute (from your playing)
  • detected tempo consistency (standard deviation; zero for perfect time)
  • percent of notes heard that were correct.
  • button to delete this single session

Advanced Page

  • Pitch Tolerance (cents)
    A note is considered correct if it is within this range.
  • RMS Threshold
    Filters out background noise below a certain level.
  • Cooldown (ms)
    Prevents repeated detection of the same note.
  • Pitch Offset (cents)
    Adjusts for systematic pitch detection error.
  • Delay Between Repeats (secs)
    Pause between repeated Random sequences. This delay time is so you can glance at the session summary in the title bar. It is common for the number of notes in the random tune to become smaller and smaller with each repeat because you have mastered more of them.

Limitations

Due to current limitations in sound detection:

  • Notes one or more octaves away may sometimes be detected as correct
  • Very low or very high notes (outside E2–E7) may not be detected
  • % Correct may appear lower than expected; a correction factor is applied

Ongoing improvements are in progress.
